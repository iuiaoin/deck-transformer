How it works

  • Same input X passes through 3 separate linear projections → Q, K, V
  • Same source, different learned transformations
  • Each token attends to all others (including itself)
  • "bank" near "river" gets different attention than "bank" near "money"

In code

Embedding — a dense vector representing a word; similar words have similar vectors.
