Positional Encoding: Teaching Order to the Transformer

Attention is position-agnostic — sin/cos positional encoding injects sequence order.

The problem

Without position info, attention treats all token positions equally.

"I love you" = "you love I"  ← same attention!
Even dimensions PE(pos, 2i) = sin(pos / 100002i/d)
Odd dimensions PE(pos, 2i+1) = cos(pos / 100002i/d)
1
Deterministic: Same position always gets the same encoding, regardless of sequence length
2
Relative distance: PE(pos+k) is a linear combination of PE(pos) — relative positions are preserved
3
Generalizes: Works for sequences longer than any seen during training

Residual connections (adding input directly to sublayer output) preserve PE through all layers:

Takeaway: Sin/cos positional encoding — deterministic, captures relative position, generalizes to any length.
