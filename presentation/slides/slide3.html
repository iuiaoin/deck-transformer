Start with something familiar — a dictionary

Attention generalizes dictionary lookup from exact match to weighted match.

Hard lookup

exact string match
{
  "apple": 10,
  "banana": 5,
  "chair": 2
}
Query: "apple" → match one key
value = 10
⟶
exact
→ soft

Soft lookup (attention)

weighted similarity
"apple"  → w = 0.6
"banana" → w = 0.4
"chair"  → w = 0.0
Query: "fruit" → no exact key
value = 0.6·10 + 0.4·5 + 0·2 = 8
jargon: a weight tells us how much each key contributes; the weights always sum to 1.
