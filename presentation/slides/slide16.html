Wrap-up

Key takeaways

Attention is all you need — literally the only operation required to build the best sequence models we have today.
1

Attention = soft dictionary lookup

Similarity between Q and K → softmax → weighted sum of values. That's the whole idea.

2

Multi-head = many perspectives in parallel

Different projections capture different kinds of relationships — syntax, coreference, long-range binding.

3

The architecture is modular

Positional Encoding + Self-Attn + FFN + LayerNorm + Residual. Stack to taste.

4

Three paradigms, one core

BERT (understand), GPT (generate), T5 (both) — all are edits of the same building blocks.
