每个 token 学习自身与同序列中所有其他 token 的关系。

工作原理

  • 同一输入 X 通过 3 个独立的线性投影 → Q、K、V
  • 相同的来源，不同的可学习变换
  • 每个 token 关注所有其他 token（包括自身）
  • “bank” 靠近 “river” 时获得的 Attention 与靠近 “money” 时截然不同

代码表示

attention(x, x, x)

Embedding — 表示词语的稠密向量；语义相近的词拥有相似的向量。

要点：Self-Attention — 每个 token 查询同一序列中的所有其他 token。
