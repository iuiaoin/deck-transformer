Part 1 · Attention from scratch

The whole formula — in a handful of lines

Attention fits in five lines of PyTorch. Masking is the one trick to learn: set blocked positions to −∞ before softmax.
def attention(q, k, v, mask=None): # q,k,v : (batch, seq_len, d_k) d_k = q.size(-1) scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(d_k) if mask is not None: scores = scores.masked_fill(mask == 0, float("-inf")) attn = F.softmax(scores, dim=-1) return torch.matmul(attn, v), attn

Why mask before softmax?

After softmax, exp(−∞) = 0 — blocked positions get exactly zero probability. Masking after softmax would leak information through the normalization.
shape evolution

  →  scores: (B, T, T)
scores × V: (B, T, d)
  →  output: (B, T, d)

One function, many flavors

Same code powers self-attn, masked self-attn, and cross-attn. Only the q/k/v inputs and the mask change.
