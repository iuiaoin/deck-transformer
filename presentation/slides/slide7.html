Part 1 · Attention from scratch

Self-Attention — the sequence looks at itself

Every token produces its own Q, K, V from the same input — so every token can attend to every other token in one matmul.

Same input X → three projections

Q = X WQ,   K = X WK,   V = X WV

In code, self-attention is literally attention(x, x, x) — the input plays all three roles. The three W matrices are learned parameters that separate the input into question, index, and payload roles.

Why it matters: distance in the sentence no longer matters — position 0 and position 999 are one matmul apart, unlike an RNN that has to walk through every step.
