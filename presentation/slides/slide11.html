Part 2 · Putting it together

Positional Encoding — attention has no sense of order

Attention is permutation-equivariant — "I love you" and "you love I" look identical. We inject order by adding a position-specific vector to every embedding.
xpos = embedding(token) + PE(pos)
# one 512-dim vector per position, added element-wise

Sinusoidal formula

PE(pos, 2i) = sin( pos / 100002i/d )
PE(pos, 2i+1) = cos( pos / 100002i/d )
PE matrix (seq_len × d_model)

Three design properties

1

Deterministic

Position 3 always gets the same vector — independent of sentence length.

2

Relative distance preserved

PE(pos+k) is a linear combo of PE(pos) — so "3 words apart" looks the same everywhere.

3

Generalizes beyond training length

sin/cos are defined at every pos — the model can handle sequences longer than it ever saw.
