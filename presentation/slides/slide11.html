SA

Multi-Head Self-Attention

Captures relationships between positions. Each token attends to all others in the sequence.

FF

Feed-Forward Network (FFN)

Two linear layers: 512 → 2048 → 512. Processes each position independently — fuses feature dimensions.

Like a 1×1 convolution — same parameters for every position (parameter sharing).
LN

LayerNorm

Normalizes activations within each sample to stabilize training across deep layers.

LayerNorm — normalizes each sample's feature vector to zero mean, unit variance.
+

Residual Connection

out = x + SubLayer(LayerNorm(x))

Lets the bottom-layer signal (including PE) flow directly to the top — prevents gradient vanishing.

Takeaway: Encoder layer = attention (between positions) + FFN (within positions) + residual shortcuts.
