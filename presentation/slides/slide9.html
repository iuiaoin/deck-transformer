Multi-Head Attention: Many Perspectives at Once

Run h parallel attention "heads" — each captures different relationship patterns.

Core Logic (reshape + compute + merge)
# Reshape: split into heads # (B, T, d_model) → (B, T, n_heads, head_dim) → (B, n_heads, T, head_dim) xq = xq.view(bsz, seqlen, self.n_heads, self.head_dim) xq = xq.transpose(1, 2) # ... same for xk, xv # Attention per head scores = torch.matmul(xq, xk.transpose(2, 3)) / math.sqrt(self.head_dim) output = torch.matmul(scores.softmax(dim=-1), xv) # Merge heads back # (B, n_heads, T, head_dim) → (B, T, d_model) output = output.transpose(1, 2).contiguous().view(bsz, seqlen, -1) output = self.wo(output) # Final linear projection

Takeaway: Multi-head attention = parallel sub-attentions, each specializing in different patterns.
