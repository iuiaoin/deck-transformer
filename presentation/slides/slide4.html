Part 1 · Attention from scratch

The three variables — Query, Key, Value

Q, K, V are just vectors. Their relationships are learned during training — not hand-written rules.
Q

Query

what am I looking for?

The vector that asks the question. In self-attention, every token produces its own query about its neighbors.

[ 0.12, −0.03, 0.47, …, 0.08 ]shape: (d_model,) — e.g. 512-dim
K

Key

how does each entry advertise itself?

What a candidate says it is "about". Similarity between Q and K determines how much that entry matters.

[ −0.22, 0.31, 0.05, …, −0.11 ]one key per token in the sequence
V

Value

what do I actually get back?

The payload — the information that gets blended into the output once the weights are computed.

[ 0.04, 0.19, −0.37, …, 0.52 ]same token count, same d_model
jargon: an embedding is a learned dense vector that represents a token in N-dimensional space — semantically similar tokens end up near each other.
