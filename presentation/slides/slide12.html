Part 2 · Putting it together

The three glue components — FFN · LayerNorm · Residual

Between attention layers, three small pieces do the heavy lifting of stable training in a deep stack.
FFN

Feed-Forward Network

2-layer MLP, per position
Linear(d→4d) · ReLU · Linear(4d→d)

Mixes features within each token. Attention mixes across tokens — FFN adds non-linear depth position by position.

shared weights: the same FFN is applied to every position (like a 1×1 conv in vision).
LN

Layer Normalization

per-token stabilization
(x − μ) / σ · γ + β

Normalizes each token's feature vector to mean 0, variance 1. Keeps activations controlled as signals flow through 6, 12, or 96 layers.

vs. BatchNorm: LayerNorm normalizes across features of one token — works with variable-length sequences.
⊕

Residual Connection

skip-around shortcut
x = x + Sublayer(x)

Lets the sublayer learn a delta rather than rewrite everything. Also guarantees the position encoding survives all the way to the top.

why it works: without residuals, training 24+ layers is unstable — gradients either vanish or explode.
Pre-Norm pattern (modern LLMs)
x = x + Attention(LN(x)) ;    x = x + FFN(LN(x))
