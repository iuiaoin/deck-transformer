1

Masked Self-Attention

Target sequence attends to itself with causal mask — each position sees only past tokens. Q = K = V = target.

2

Cross-Attention

Q = decoder state, K & V = encoder output (memory). This is how the decoder "reads" the source sequence.

3

Feed-Forward Network

Same position-wise FFN as encoder: 512 → 2048 → 512. Processes each position independently.

Autoregressive generation: At inference, the decoder generates one token at a time, feeding each output back as the next input — until an end-of-sequence token appears.

Encoder vs Decoder: Encoder has 2 sub-layers. Decoder has 3 (extra cross-attention to read the encoder).
Takeaway: Decoder = masked self-attention + cross-attention (reads encoder) + FFN.
